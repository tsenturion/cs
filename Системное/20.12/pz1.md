### Цель задания

Закрепить на практике умение:

* получать информацию о процессах;
* запускать внешний процесс из C#;
* ожидать завершения процесса;
* анализировать состояние процесса и его код выхода;
* корректно работать с API `System.Diagnostics.Process`.

### Условие задания

Необходимо написать **консольное приложение на C#**, которое выполняет следующие действия:

1. Выводит информацию о **текущем процессе**:

   * PID процесса
   * имя процесса
   * время запуска
   * количество потоков

2. Запускает **внешний процесс** (любой стандартный системный, например `notepad.exe`).

3. После запуска:

   * выводит PID дочернего процесса;
   * проверяет, запущен ли процесс.

4. Ожидает завершения дочернего процесса.

5. После завершения:

   * выводит сообщение о завершении;
   * выводит код выхода процесса.

### Ограничения и требования

* Использовать только стандартные средства .NET.
* Работа с процессами должна выполняться через `System.Diagnostics`.
* Код должен быть читаемым и сопровождаться комментариями.
* Запрещено использовать принудительное завершение процесса (`Kill`).
* Приложение должно корректно завершаться без исключений.

### Подсказки

* Для получения информации о текущем процессе используйте `Process.GetCurrentProcess()`.
* Для запуска внешнего приложения используйте `Process.Start()`.
* Для ожидания завершения процесса используйте `WaitForExit()`.
* Перед чтением `ExitCode` убедитесь, что процесс завершен.

### Чек лист выполнения

* Используется ли `System.Diagnostics.Process`, а не сторонние решения.
* Корректно ли получена информация о процессе.
* Есть ли понимание разницы между текущим и дочерним процессом.
* Нет ли принудительного завершения процесса.
* Есть ли комментарии и аккуратная структура кода.


### Возможные доработки (по желанию)

* Добавить обработку исключений (`try-catch`).
* Реализовать запуск процесса с аргументами.
* Добавить вывод времени работы дочернего процесса.
* Сделать выбор запускаемого приложения через ввод пользователя.
