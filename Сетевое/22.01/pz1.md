# Практическое задание: "Распределённый чат на низкоуровневых сокетах"

## Контекст задания

Вы разрабатываете прототип распределённого чата для внутреннего использования в компании. Система должна работать на низкоуровневых сокетах без использования высокоуровневых библиотек. Ваша задача — реализовать базовую функциональность, демонстрирующую понимание архитектуры сокетов в .NET.

## Цели выполнения

1. Понимание жизненного цикла сокетов
2. Работа с состояниями соединений
3. Обработка асинхронных операций
4. Управление системными ресурсами
5. Архитектурное разделение ответственности

## Базовые требования

### Часть 1: Класс ConnectionManager

Реализуйте класс `ConnectionManager`, который будет отвечать за:

- Создание и настройку сокетов
- Управление состояниями соединений
- Обработку сетевых ошибок
- Корректное освобождение ресурсов

**Требования:**

- Использовать классы из `System.Net` и `System.Net.Sockets`
- Реализовать состояния: `Disconnected`, `Connecting`, `Connected`, `Error`
- Поддержка IPv4 и IPv6
- Корректная обработка `IDisposable`

### Часть 2: Текстовый протокол

Реализуйте простой текстовый протокол для обмена сообщениями:

```text
[команда]:[параметры]|[данные]
```

Примеры:

- `MSG:username|Hello everyone!`
- `JOIN:username|`
- `LEAVE:username|`

**Требования:**

- Парсинг входящих сообщений
- Валидация формата сообщений
- Обработка некорректных данных
- Кодировка UTF-8

### Часть 3: Сервер чата

Реализуйте сервер, который:

1. Принимает подключения от клиентов
2. Рассылает сообщения всем подключённым клиентам
3. Управляет списком активных пользователей
4. Обрабатывает отключения клиентов

## Пример использования

```csharp
// Сервер
using var server = new ChatServer(port: 12345);
await server.StartAsync();

// Клиент 1
using var client1 = new ChatClient();
await client1.ConnectAsync("127.0.0.1", 12345);
await client1.SendMessageAsync("Alice", "Hello!");

// Клиент 2
using var client2 = new ChatClient();
await client2.ConnectAsync("127.0.0.1", 12345);
var message = await client2.ReceiveAsync(); // Получит "Alice: Hello!"
```

## Тестовые сценарии

1. **Одиночное подключение:**
   - Клиент подключается, отправляет сообщение, отключается

2. **Множественные клиенты:**
   - 5 клиентов подключаются одновременно
   - Каждый отправляет 10 сообщений
   - Все сообщения доставляются всем клиентам

3. **Ошибки сети:**
   - Разрыв соединения во время передачи
   - Недоступный сервер
   - Некорректные данные от клиента

4. **Нагрузочное тестирование:**
   - 1000 быстрых подключений/отключений
   - Длительная работа (10+ минут)
   - Утечки памяти

## Подсказки

1. **Начните с проектирования состояний:**

   ```mermaid
   graph TD
       A[Disconnected] -->|Connect| B[Connecting]
       B -->|Success| C[Connected]
       B -->|Error| D[Error]
       C -->|Disconnect| A
       C -->|NetworkError| D
       D -->|Retry| B
   ```

2. **Используйте паттерны:**
   - `async/await` для всех сетевых операций
   - `CancellationToken` для управления жизненным циклом
   - `ConcurrentDictionary` для хранения клиентов

3. **Тестируйте постепенно:**
   1. Простое эхо-соединение
   2. Добавьте протокол
   3. Добавьте множественных клиентов
   4. Добавьте обработку ошибок

**Важно:** Не используйте `TcpClient`, `TcpListener`, `UdpClient` - только низкоуровневые сокеты (`System.Net.Sockets.Socket`).
