# Практическое задание

**Тема:** Поведение HTTP/HTTPS в C# и диагностика TLS-ошибок

## Цель

Закрепить понимание того, что **HTTPS = HTTP + TLS**, и научиться на практике различать в коде:

* ошибки уровня **TLS / сертификатов** (до начала HTTP),
* ошибки уровня **HTTP** (после установления защищённого соединения),
* ошибки **сети** (TCP, DNS, таймауты).

## Задание (шаги)

1. **Создайте консольное приложение на C# (.NET).**

2. **Реализуйте класс `RequestRunner`** с методом:

   ```text
   Task<Result> RunAsync(Uri uri, CancellationToken cancellationToken)
   ```

   где `Result` содержит:

   * `Uri`
   * `bool Success`
   * `int? StatusCode`
   * `string? ErrorType` (например: `Network`, `Tls`, `Http`, `Unknown`)
   * `string? ErrorMessage`
   * `long DurationMs`
   * `int? BodyPreviewLength`

3. **Выполните три запроса, используя один экземпляр `HttpClient`:**

   * `http://example.com`
   * `https://example.com`
   * `https://expired.badssl.com/` (или другой HTTPS-ресурс с гарантированной ошибкой сертификата)

4. **Для каждого запроса:**

   * измерьте время выполнения;
   * при успешном ответе выведите HTTP-код и первые 200 символов тела;
   * при ошибке зафиксируйте тип ошибки и сообщение исключения.

5. **Реализуйте явное разделение ошибок:**

   * TLS-ошибка — HTTP-ответ отсутствует, соединение не установлено;
   * HTTP-ошибка — ответ получен, но код 4xx/5xx;
   * таймаут — отмена через `CancellationTokenSource`.

6. **Сформируйте итоговый вывод в консоль:**

   * список результатов по всем URI;
   * краткий вывод о том, в каких случаях HTTP-запрос не был выполнен и по какой причине.

## Подсказки по ключевым частям

* TLS-рукопожатие происходит **до отправки HTTP-запроса**.
* При ошибке сертификата объект `HttpResponseMessage` не создаётся.
* Для классификации ошибок анализируйте:

  * тип исключения (`HttpRequestException`, `AuthenticationException`, `TaskCanceledException`);
  * наличие или отсутствие HTTP-ответа.
* Используйте **один экземпляр `HttpClient`** на все запросы.
* Не отключайте проверку сертификатов для упрощения задания.

## Что проверить перед отправкой (чек-лист)

* [ ] Используется один общий `HttpClient`
* [ ] Для каждого URL зафиксировано время выполнения
* [ ] TLS-ошибки не смешиваются с HTTP-ошибками
* [ ] HTTP-коды 4xx/5xx корректно обрабатываются как ответы сервера
* [ ] Таймаут реализован через `CancellationToken`
* [ ] В коде отсутствует глобальное отключение проверки сертификатов

## Советы по улучшению работы

* Добавьте повторные попытки (retry) **только** для сетевых ошибок и таймаутов.
* Реализуйте логирование этапов выполнения запроса (старт, ответ, исключение).
* Сравните время первого и повторного HTTPS-запроса (переиспользование TLS-соединения).
* Добавьте чтение списка URL из аргументов командной строки.
* Реализуйте вывод результатов в формате JSON для удобства анализа.
